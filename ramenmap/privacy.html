라멘지도 개인정보처리방침

최종 수정일: 2026년 9월 8일

라멘지도(이하 "앱")는 이메일·전화번호·이름 등 개인을 식별하는 정보를 수집하지 않습니다. 회원가입도 로그인도 없습니다. 아래는 앱이 다루는 정보 전부입니다.

1. 이 기기에만 저장되는 것

정보용도저장 위치
방문 도장(가게·날짜), 그릇 점수, 먹은 라멘 종류, 한 줄 메모, 가고싶다 표시내 도장첩 표시이 기기. 설정 > 내보내기로 사용자가 직접 꺼낼 수 있습니다
가게 목록 캐시오프라인에서도 지도 표시이 기기

그릇 점수와 메모는 서버로 보내지 않습니다.

2. 순위표에 참여하면 서버에 저장되는 것 (선택)

순위 탭에서 닉네임을 정한 경우에만 아래 정보가 운영자 서버(AWS 서울 리전)에 저장됩니다. 닉네임을 정하지 않으면 서버에는 아무것도 저장되지 않습니다.

정보용도보관
기기가 무작위로 만든 익명 토큰(의 해시)같은 기기의 도장을 한 사람 것으로 묶기앱을 삭제하면 토큰이 사라져 더 이상 연결되지 않습니다
닉네임순위표에 공개 표시사용자가 언제든 바꿀 수 있습니다
도장의 가게·날짜·현장 인증 여부순위 계산, 가게별 「현장 인증 도장 N명」 표시도장을 지우면 서버에서도 지워집니다

위치 정보는 저장하지 않습니다. 도장을 찍는 순간의 위치는 「가게 500m 안인가」를 판정하는 데 한 번 쓰이고 그 결과(인증 여부)만 남습니다. 좌표 자체는 서버에 기록하지 않습니다.

3. 위치 정보

앱은 사용자가 허용한 경우에만 현재 위치를 사용합니다. 용도는 두 가지입니다: 가까운 라멘집을 거리순으로 보여주기, 도장의 현장 인증 판정. 위치는 기기 밖으로 저장·전송되지 않으며(인증 판정 요청 시 서버에 한 번 전달되고 저장되지 않음), 허용하지 않아도 앱의 모든 기능을 쓸 수 있습니다(목록은 이름순, 도장은 미인증으로 기록).

4. 자동으로 전송되는 것

가게 목록을 내려받거나 지도 타일을 불러올 때 서버(운영자 서버, OpenStreetMap 타일 서버)에 IP 주소와 앱 식별자(User-Agent)가 일반적인 인터넷 통신 과정에서 전달됩니다. 이를 별도로 수집·분석하지 않습니다. 광고·분석 SDK는 포함하지 않습니다.

5. 가게 정보의 출처

가게 이름·주소·좌표·전화번호는 카카오 로컬 API 검색 결과입니다. 영업시간·휴무는 싣지 않습니다. 정보 오류나 게시 중단 요청은 아래 연락처로 보내주시면 확인 후 처리합니다.

6. 삭제

  • 기기 기록: 설정 > 기록 전부 지우기, 또는 앱 삭제
  • 서버 기록: 도장을 지우면 즉시 삭제됩니다. 닉네임·전체 기록 삭제는 아래 연락처로 요청하시면 7일 안에 처리합니다. 앱을 삭제하면 토큰이 사라져 서버 기록은 누구와도 연결되지 않는 상태가 되며, 90일 뒤 정리됩니다.
