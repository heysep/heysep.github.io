Reset Radar checks four public places. A reset is only called Confirmed when an official page says so. Posts from people can raise a signal, never confirm it.

One push per reset, only when something is detected

No daily reminders. If nothing happened, your phone stays quiet.

S

Status page

Official. Incident open and resolved notices count as supporting signals, not reset announcements.

C

Changelog

Official. A new entry that mentions a limit reset is the only thing that can make a reset Confirmed.

R

Reddit

Public posts. Several different authors mentioning a reset raise the signal to Likely. One post stays a watch.

X

X (when available)

Only if the service has access. When it does not, the app shows it as unavailable instead of a quiet zero.

What it cannot do

  • It is not an official app and has no connection to OpenAI.
  • It cannot grant, extend or guarantee a reset. It only tells you when public signals say one happened.
  • Detection uses public signals and can miss a reset or be wrong. Accuracy has not been measured yet.
  • Reddit and X signals are never shown as Confirmed.

Questions

Does it need an account?

No. There is no sign-up. The app asks for notification permission only when you tap the card that turns alerts on.

What do you store about me?

A push token, your language and your alert rules, so the server can send the notification. You can delete all of it from Settings. Details are in the privacy policy.

Why not use a joke countdown site?

Those show a number with no evidence. This app shows the post or page behind each alert, and a source that is down is shown as unavailable.

Is it free?

The core is free. Pro is a one-time purchase if you want widgets, rules and full history.
